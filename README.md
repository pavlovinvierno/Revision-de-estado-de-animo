# Registro de Estado v10 — PWA

Sistema local de seguimiento longitudinal de sueño, estado, contexto y funcionamiento.

## Novedades v10
- Registro rápido de baja carga.
- Detección de brechas de observación >=24 h sin imputar síntomas.
- Clasificación opcional de la causa de una brecha.
- Registros retrospectivos diferenciados de observaciones en tiempo real.
- Sueño independiente y tiempo despierto derivado.
- Exportación JSON/CSV e informe imprimible.
- Persistencia local y funcionamiento offline.

Los datos se almacenan localmente en el navegador. El sistema no pretende establecer diagnósticos ni causalidad.
